# 🏋️ Training bot — персональный тренер в Telegram

Telegram-бот, который составляет программу тренировок и считает КБЖУ под цель человека, ведёт дневник тренировок, следит за прогрессом и напоминает о занятиях. Программы составляет нейросеть: бесплатная (через OpenRouter, Groq и другие OpenAI-совместимые API) или Claude.

## Возможности

| | |
|---|---|
| 👤 **Анкета** | Пол, возраст, рост, вес, цель, опыт, место тренировок, инвентарь, частота, длительность, травмы. Для зала бот сам подставляет стандартный набор тренажёров |
| 📋 **План тренировок** | Нейросеть составляет недельную программу: упражнения, подходы, повторы, отдых, подбор веса, разминка, прогрессия. Учитывает травмы |
| 🥗 **КБЖУ** | Калории и белки/жиры/углеводы по формуле Миффлина — Сан Жеора с поправкой на активность и цель, плюс советы по питанию |
| ✍️ **Дневник** | Запись результатов по упражнениям (`60 x 10 10 9`), прошлый результат, подсказка, когда добавлять вес, рекорды и тоннаж |
| 📈 **Прогресс** | Динамика весов по упражнениям и веса тела с мини-графиками |
| ⚖️ **Замеры** | Вес и талия; раз в месяц бот сам напомнит обновить |
| ⏰ **Напоминания** | Дни недели и время тренировок — бот напомнит, какая тренировка по плану |
| 🔍 **Разбор плана** | Пришли свою программу — нейросеть скажет, что в ней поменять |
| 📖 **Техника** | Как правильно выполнять упражнение + ссылка на видео. Ответы кешируются |
| 🛡 **Прокси / VPN** | Владелец может прямо в боте задать прокси для запросов к нейросети (`/proxy`) |

Дневник, прогресс, замеры, КБЖУ и напоминания работают без нейросети.

## Быстрый старт

### 1. Что понадобится

- **Токен бота** — создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot`.
- **Ключ нейросети** — один из вариантов:
  - **Бесплатно:** [OpenRouter](https://openrouter.ai/keys) (модели с суффиксом `:free`) или [Groq](https://console.groq.com/keys). У бесплатных тарифов есть дневные лимиты, а модели иногда пропадают — поэтому в настройках можно указать несколько моделей подряд.
  - **Платно и умнее:** [Claude API](https://platform.claude.com). Один план стоит примерно 5–10 центов на `claude-opus-5-5`.
- **Твой Telegram ID** — напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число.
- **Сервер** с Ubuntu 22.04+ (хватит 1 ядра и 512 МБ памяти).

### 2. Установка на сервер

```bash
git clone https://github.com/lxzrl/Training-bot.git
sudo bash Training-bot/install.sh
```

Скрипт сам спросит четыре вещи — токен бота, ключ нейросети, твой Telegram ID и VLESS-ссылку для VPN (её можно пропустить):

```
1/4. Токен бота от @BotFather: ••••••
   ✓ Бот найден: @my_fit_bot
2/4. Ключ нейросети (OpenRouter sk-or-..., Groq gsk_... или Claude sk-ant-...): ••••••
   ✓ OpenRouter (бесплатные модели)
3/4. Твой Telegram ID (узнать: напиши @userinfobot): 123456789
   Необязательно: ID друзей через запятую (Enter — бот будет открыт всем): 111,222
4/4. VLESS-ссылка vless://... (Enter — без VPN): ••••••
   ✓ VPN работает, внешний IP: 203.0.113.7
```

Нейросеть определяется по ключу автоматически. Дальше скрипт поставит зависимости, запустит бота и скажет, всё ли в порядке. Бот ставится как systemd-сервис `fitbot` с лимитом памяти 250 МБ, поэтому спокойно уживается с другими ботами на сервере.

Поменять токен, ключ или список друзей: `sudo bash Training-bot/install.sh --setup`.
Настроить или поменять VPN: `sudo bash Training-bot/install.sh --vpn`.

### 3. Обновление

```bash
cd Training-bot && git pull && sudo bash install.sh
```

Настройки (`.env`) и база данных при обновлении не трогаются.

## Настройки (`/opt/fitbot/.env`)

| Параметр | Что значит |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_ID` | Твой Telegram ID — владелец может управлять прокси |
| `ALLOWED_USERS` | ID друзей через запятую. Пусто — бот открыт всем |
| `AI_PROVIDER` | `openai` — любой OpenAI-совместимый API (бесплатные варианты), `claude` — Claude API |
| `OPENAI_BASE_URL` | Адрес API: `https://openrouter.ai/api/v1`, `https://api.groq.com/openai/v1` и т.д. |
| `OPENAI_API_KEY` | Ключ этого API |
| `OPENAI_MODEL` | Модель или несколько через запятую — если первая недоступна, бот попробует следующую. Бесплатные модели OpenRouter: [openrouter.ai/models?q=free](https://openrouter.ai/models?q=free) |
| `ANTHROPIC_API_KEY` | Ключ Claude API (для `AI_PROVIDER=claude`) |
| `CLAUDE_MODEL` | `claude-opus-5-5` (умнее) или `claude-haiku-5-5` (примерно в 40 раз дешевле) |
| `AI_DAILY_LIMIT` | Сколько запросов к нейросети в день на человека (по умолчанию 15) |
| `TIMEZONE` | Часовой пояс напоминаний, например `Europe/Moscow` |
| `PROXY_URL` | Начальный прокси для нейросети. Удобнее менять командой `/proxy` |

После изменения `.env`: `sudo systemctl restart fitbot`.

## Прокси и VPN

Некоторые нейросети недоступны из части стран — тогда бот ответит «Нейросеть недоступна с этого сервера». Решение — пустить запросы к нейросети через VPN или прокси. Через них идут **только** запросы к нейросети — Telegram и остальной сервер работают напрямую.

### VLESS

Установщик спрашивает ссылку `vless://...` (её даёт твой VPN-сервис или панель 3x-ui / Marzban). Отдельно: `sudo bash Training-bot/install.sh --vpn`.

Скрипт сам скачает [Xray](https://github.com/XTLS/Xray-core), соберёт из ссылки конфиг (поддерживаются Reality, TLS, транспорты tcp, ws, grpc, xhttp, httpupgrade), запустит его как сервис `fitbot-vpn` с локальным socks5 на `127.0.0.1:10818`, проверит связь и подключит к боту. Ссылку на VPN можно поменять той же командой.

### Прокси из Telegram

Владелец (`ADMIN_ID`) может поменять прокси прямо в боте:

```
/proxy                                    — текущие настройки и проверка связи
/proxy socks5://логин:пароль@адрес:порт   — задать прокси (сообщение с паролем бот удалит)
/proxy off                                — выключить
```

Поддерживаются `http://`, `https://` и `socks5://`. Настройка из бота главнее `.env`; повторный запуск `install.sh --vpn` снова делает главной настройку установщика.

## Полезные команды на сервере

| Что | Команда |
|---|---|
| Логи в реальном времени | `journalctl -u fitbot -f` |
| Логи VPN | `journalctl -u fitbot-vpn -f` |
| Перезапустить | `sudo systemctl restart fitbot` |
| Остановить | `sudo systemctl stop fitbot` |

## Запуск локально

```bash
python -m venv venv
venv/bin/pip install -r requirements.txt     # на Windows: venv\Scripts\pip
cp .env.example .env                         # и заполни
venv/bin/python bot.py
```

## Как устроено

```
bot.py            запуск, роутеры, команды
ai.py             запросы к нейросети (Claude или OpenAI-совместимый API), прокси
athlete.py        анкета, ИМТ, КБЖУ, описание клиента для нейросети
progression.py    разбор записи «60 x 10 10 9» и подсказки по прогрессии
scheduler.py      напоминания о тренировках и замерах
db.py             SQLite
handlers/         экраны бота: анкета, план, дневник, прогресс, замеры, напоминания, техника, разбор, прокси
install.sh        установка на Ubuntu: мастер настройки, systemd-сервис, VPN
vpn/              конвертер ссылки vless:// в конфиг Xray
```

Стек: Python 3.10+, [aiogram 3](https://docs.aiogram.dev), SQLite, Anthropic и OpenAI SDK.

> ℹ️ Бот не заменяет врача и тренера вживую. При травмах и болезнях согласуйте нагрузку со специалистом.
